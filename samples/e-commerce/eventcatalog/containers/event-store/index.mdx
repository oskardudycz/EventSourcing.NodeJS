## Overview

Each module appends its events to its own streams, in its own database, and reads a stream to rebuild a state. Consumers read the events again to run the workflows and to forward the external events. The `EVENTSTORE_TYPE` setting picks SQLite (a file for each module) or PostgreSQL (a schema for each module).
