### Quality-1. "First write of each document" makes every outbox commit in a handler fail

Quote: "the first write of each document (a store, a delete, or a transaction commit that includes it) ... always fail"; "JVM's `OutboxMessage` / `OutboxCheckpoint` are the reference"; 6.2.
Consequence: The reference outbox stores each message under a new random id on every attempt (JVM `Outbox.java:36`, .NET `Outbox.cs:27,38`), so every handler commit with events contains a never-written document and always fails, until the bus gives up. The solutions' business process tests would fail every run.
Belongs to: spec
Resolution: fixed in r2: Oskar, "a)" (Q15): the first database write of each test and the first publish of each message type fail, then 1 in 3; calls straight from a test never fail and don't count.
