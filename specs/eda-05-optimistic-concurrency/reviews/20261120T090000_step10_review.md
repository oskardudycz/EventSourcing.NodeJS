### Standards-2. Node.js `AggregateStore` casts its event type

Quote: `aggregateStore.ts`: `Promise<ReturnType<A['dequeueUncommitedEvents']>>`, `return [] as ReturnType<A['dequeueUncommitedEvents']>;`, `aggregate.dequeueUncommitedEvents() as ReturnType<A['dequeueUncommitedEvents']>`. `commandHandler.ts` uses a plain `E extends Event` and `E[]`.
Consequence: the two casts switch off type checking on the returned events, and a workshop reader has to decode `ReturnType<A[...]>`. This conflicts with "Prefer simple, easily removable code". A second type parameter for the event type (`AggregateStore<A, E>`) removes the casts.
Belongs to: implementation
